# Terabot – [AI-Based] Mental Health Support Chatbot

Terabot is an AI-powered conversational chatbot designed to provide supportive mental health conversations using Natural Language Processing (NLP) and transformer-based language models. It uses Facebook's BlenderBot model to generate conversational responses based on user input and conversation history.

The project explores how conversational AI can be used to create accessible, interactive mental health support tools.

## Project Objectives

- Develop an AI-powered conversational chatbot.
- Generate context-aware responses using NLP.
- Explore transformer-based language generation.
- Prepare and combine mental health conversation datasets.
- Explore Google Sheets integration for storing conversation interactions.

## Key Features

- **AI-Based Conversations:** Generates responses using the BlenderBot model.
- **Context Awareness:** Maintains recent conversation history to improve response relevance.
- **NLP Processing:** Uses tokenization and text preprocessing techniques.
- **Dataset Integration:** Combines mental health chatbot and counseling conversation datasets.
- **Conversation Logging:** Includes Google Sheets integration for recording interactions.

## Datasets

The project uses two conversational datasets:

1. **Mental Health Chatbot Dataset**
   - Source: heliosbrahma/mental_health_chatbot_dataset

2. **Mental Health Counseling Conversations**
   - Source: Amod/mental_health_counseling_conversations

The datasets are combined and processed to prepare conversational context and response pairs.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Nishant08y/Terabot-AI-Mental-Health-Chatbot.git
```

### 2. Navigate to the project directory

```bash
cd Terabot-AI-Mental-Health-Chatbot
```

### 3. Install dependencies

```bash
pip install transformers datasets tensorflow pandas sentencepiece accelerate huggingface_hub gspread oauth2client torch
```

### 4. Run the project

Open `code_1.py` in Google Colab or a compatible Python environment.

Note: The current script contains notebook-style installation commands. Adapt these commands if running it as a standard Python script. Google Sheets integration also requires valid Google service account credentials and a configured spreadsheet.

## How It Works

1. Loads the mental health conversational datasets.
2. Cleans and combines the conversational data.
3. Tokenizes the input and response text.
4. Loads the pre-trained Facebook BlenderBot model.
5. Fine-tunes the model using the prepared conversational dataset.
6. Generates responses based on user input and recent chat history.
7. Includes functionality to log conversations to Google Sheets.
